ทักษะและเครื่องมือ

แยกเป็นสามกลุ่มตามบทบาทการใช้งาน รายการที่มีคำอธิบายกำกับคือสิ่งที่ใช้ทำงานจริงเป็นประจำ ส่วนป้ายท้ายกลุ่มคือสิ่งที่หยิบมาใช้ร่วมเป็นครั้งคราว

ภาษาที่ใช้พัฒนา

ภาษาที่เขียนเองในงานจริง
  • PHP ภาษาหลักของงานหลังบ้านตลอด 6 ปี
  • SQL ออกแบบตารางและเขียน query เอง
  • JavaScript งานฝั่งหน้าเว็บและเรียก API
  • HTML / CSS โครงหน้าเว็บและงาน responsive
  • Python งาน Automation เชื่อม SAP และจัดการไฟล์ข้อมูล
กำลังศึกษา Golang

เฟรมเวิร์กและไลบรารี

ตัวช่วยที่สร้างงานอยู่บนนั้น
  • Laravel ระบบหลังบ้านที่ใช้งานจริงใน Production
  • Bootstrap โครงเลย์เอาต์และคอมโพเนนต์ UI
  • AJAX โหลดและส่งข้อมูลโดยไม่รีเฟรชหน้า
  • Pandas ทำ Data Cleansing ก่อนขึ้นแดชบอร์ด

เครื่องมือและแพลตฟอร์ม

สิ่งที่ใช้ทำงานทุกวัน
  • ฐานข้อมูล PostgreSQL · MySQL · SQL Server
  • Docker ยกระบบและฐานข้อมูลขึ้นรันเป็นชุดเดียว
  • Git / GitHub ควบคุมเวอร์ชันทุกโปรเจกต์
  • WordPress เขียนธีมเองทั้งชุด 2 เว็บบริษัท
  • cPanel ดูแลโฮสต์ โดเมน และระบบสำรองข้อมูล
  • Windows Server ตั้งค่าเซิร์ฟเวอร์ โดเมน SSL และ Deploy
  • Looker Studio แดชบอร์ดสรุปข้อมูลให้ผู้บริหาร
  • Google Sheets ต้นทางข้อมูลที่ต่อเข้าแดชบอร์ด
  • Postman ทดสอบและทำเอกสาร API
  • Figma ร่าง Wireframe และวาง UI ก่อนลงมือ
